# Acceso-a-internet-en-las-escuelas
Se analiza el acceso a internet en las escuelas con fines pedagógicos


Se cuenta una “historia de datos” sobre el acceso a Internet con fines pedagógicos en escuelas de distintos países, explorando su evolución en el tiempo, las diferencias por nivel educativo y por país. Se usó pandas para limpiar los datos (conversión numérica, eliminación de nulos), agrupar con groupby (media, mediana y conteo por año, nivel y país), y pycountry para identificar países a partir de códigos M49; se elaboraron gráficos de línea y barras con matplotlib aplicando principios de visualización de Gestalt, Tufte y Nigel Holmes (etiquetas directas, escala de 0 a 100 %, sin elementos decorativos). 

Conclusiones: Muchos registros muestran niveles altos de conectividad escolar, pero persisten diferencias entre niveles educativos y países, y la cantidad de datos disponibles cambia entre años, por lo que los resultados describen los registros existentes y no una medición mundial comparable; así, la brecha digital educativa no ha desaparecido.
